# Generative AI Daily Learning 

Welcome to my daily Generative AI learning journey! This repository is dedicated to documenting everything I learn, experiment with, and build in the field of Generative AI every day.

---

##  Purpose & Goals

- **Consistency:** Learn and practice GenAI concepts every day.
- **Hands-on Practice:** Build small experiments, prototypes, and real-world projects.
- **Knowledge Base:** Keep clean notes, summaries, references, and code snippets for future reference.

---

##  Topics & Roadmap

- **Foundations:**
  - LLM basics, prompt engineering, tokenization, embeddings
  - Transformer architectures & attention mechanisms
- **Frameworks & Tools:**
  - LangChain, LlamaIndex, Hugging Face Transformers
  - Vector databases (Chroma, Pinecone, FAISS, Qdrant)
  - API integrations (OpenAI, Gemini, Anthropic, open-source local models via Ollama/vLLM)
- **Advanced Techniques:**
  - Retrieval-Augmented Generation (RAG) & Advanced RAG pipelines
  - Autonomous agents, multi-agent systems, function calling, MCP
  - Fine-tuning (LoRA, QLoRA, PEFT, RLHF, DPO)
  - Evaluation & observability (eval frameworks, tracing)
- **Multimodal & Diffusion:**
  - Vision-language models (VLMs)
  - Image generation (Diffusion models, Stable Diffusion, Flux)
  - Audio & speech synthesis
